## Glow Salon

A modern, elegant, and fully responsive beauty salon website built using **HTML**, **CSS**, and **JavaScript**. Designed with a focus on aesthetics, usability, and performance, this project delivers a seamless user experience across desktops, tablets, and mobile devices.
